RESPONSIVE DESIGN
The website uses fluid percentage-based widths and separate CSS stylesheets for three viewport sizes:
- Mobile: 480px and below (css/mobile.css). Content is stacked vertically to fit narrow screens.
- Tablet: 481px to 960px (css/tablet.css). Content is stacked to maintain readability at medium screen widths.
- Laptop: 961px and above (css/laptop.css). The wider layout displays content side by side, including two project boxes per row.
The shared styles are in css/style.css. Media queries select the appropriate stylesheet for each viewport. Flexbox is not used.

LINEAR GRADIENTS
- Regular linear gradient: Used in the website header, from #552D38 to #8A5362.
- Angled linear gradient: Used in the navigation bar at 45 degrees, from #552D38 to #8A5362.
Both gradients are defined in css/style.css.

COLOUR SCHEME
The website uses a burgundy-based colour scheme, with the following colours:
- #552D38: Dark burgundy for headings, footer, buttons, and gradient backgrounds.
- #8A5362: Lighter burgundy for gradients, borders, and hover effects.
- #F1E8E6: Light background colour.
- #FFFFFF: White content boxes and light text.
- #252525: Dark body text.
Adobe Color palette tool: https://color.adobe.com/create
